# Invitación de Boda - Classic Burgundy

Invitación interactiva y elegante de boda con sobre animado, secciones informativas (Detalles, Nuestra Historia, RSVP) y formulario de confirmación integrado con WhatsApp.

## Características
- Animación de apertura de sobre con video.
- Secciones completas: Portada (Home), Detalles (Details), Nuestra Historia (Love Story) y Reservaciones (RSVP).
- Formulario RSVP simplificado conectado a WhatsApp con validación de datos.
- Diseño 100% responsivo y adaptado para dispositivos móviles y escritorio.

## Despliegue en Vercel
Este repositorio está listo para desplegar en Vercel:
1. Importa el repositorio en Vercel.
2. Mantén la configuración por defecto y haz clic en **Deploy**.
